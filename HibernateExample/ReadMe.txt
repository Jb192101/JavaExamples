Для примера будет использована работа с таблицей, приведённая в файле employees.sql.

В примере использовались:
- сборщик Maven;
- СУБД PostgreSQL;

Файл hibernate.cfg.xml должен лежать в папке resources.

Примеры:
- Файл Test1.java : пример с добавлением объекта класса Employee в таблицу;
- Файл Test2.java : пример с добавлением и чтением объекта;
- Файл Test3.java : чтение сущностей из таблицы в List<>.
